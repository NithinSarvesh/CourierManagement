# Courier Management System - Frontend

This is a UI-only React/Vite frontend. It does NOT connect to or modify the backend.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the localhost URL shown by Vite.

The pages currently use sample data so the UI works without the backend. Your groupmate can later replace the sample data with API integration.
